Instructions

  • 0. Preparatory step — we need tools:
    • 0. Installed ADB and Fastboot
    • 1. Odin
    • 2. Samsung USB drivers
    • 3. Custom firmware (GSI) — download firmware versions that support arm64 (other firmware versions will not run)
    • 4. Official stock firmware of your device version
    • 5. Download TWRP
    • 6. Enable USB debugging in Developer Settings
    • 7. In Odin, disable Auto Reboot (Options → uncheck Auto Reboot: ☑ → ☐)
  • 1. Unlock the bootloader:
    • Enable OEM Unlocking in Developer Settings.
    • Connect the tablet to the computer and turn it off.
    • When the screen goes out, hold Power + VOL+ + VOL- to enter Odin (Download) mode.
    • Press and hold VOL+ for 7 seconds to unlock the bootloader (your data will be deleted).
    • After unlocking, the tablet will reboot — immediately press VOL+ and VOL- to go back into Odin mode.
  • 2. Flash TWRP:
    • Back in Odin mode, flash TWRP through the AP section.
    • After flashing, reboot the tablet by holding Power + VOL- for 7–8 seconds.
    • Immediately after the screen goes out, hold VOL+ until the tablet boots into TWRP.
    Note: Unlocking the bootloader erases user data. If you boot straight into TWRP without going through initial setup, TWRP may reboot once — this is normal; just hold VOL+ when the screen goes out to return to TWRP.
  • 3. Format Data in TWRP:
    • From the TWRP main menu, tap Wipe (Erase) → Format Data and type Yes.
  • 4. Reboot to Fastboot:
    • Go back to the TWRP main menu and select Reboot → Fastboot.
  • 5. Prepare the GSI image:
    • Copy your custom firmware into the ADB / Fastboot folder and rename it to something simple (e.g., instructions.img).
  • 6. Prepare Stock Recovery:
    • Extract recovery.img from the AP archive of your official stock firmware and place it in the same ADB / Fastboot folder.
  • 7. Flash the GSI:
    • Run fastboot flash system instructions.img and wait for it to finish.
  • 8. Flash Stock Recovery:
    • Run fastboot flash recovery recovery.img.
  • 9. Reboot:
    • Run fastboot reboot.
  • 10. Final Format Data (if prompted):
    • After flashing, the tablet may reboot twice and enter stock recovery; if so, select Format Data → Yes.
  • 11. Done:
    • The tablet will now boot into your custom firmware (GSI).

Rooting Instruction

This is an optional offshoot of the main guide if you need root:

  • Download magisk.zip and Magisk.apk and copy them to your SD card (Magisk.apk is needed in case it doesn't appear automatically after flashing).
  • After Step 7, run:
fastboot reboot recovery
  • In TWRP, tap Install → Select Storage → choose SD Card.
  • Select magisk.zip and swipe to flash it.
  • Return to the TWRP main menu, select Reboot → Fastboot, and continue from Steps 8–11.
